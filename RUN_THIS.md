# Run the game

1. Open the repository folder in Godot 4.7.
2. The main scene is `Main.tscn` and uses GDScript only.
3. Press F6 or Run Project.
4. WASD / arrows move.
5. J attacks, K defends.

If Godot shows an old scene tree, use Project > Reload Current Project and then Run Project. The playable scene no longer depends on the C# project files.
